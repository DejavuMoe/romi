# Changelog

## 3.0.0 — 2026-10-31

- Independent, project-local design capability system with no Baoyu-Design runtime dependency.
- Shared foundations and component guidance for UI, slides, documents, brand visuals, diagrams and data dashboards.
- Task-specific references, medium-specific verification and capability-based tool fallbacks.
- Project-owned design-review.json replaces the upstream approval format; explicit migration guidance for 2.x projects.
- UI implementation gate checks all declared prototype files and current mappings, including binary assets.
- Project-only installation guidance, revised behavior evaluations and dependency-drift regression tests.

## 2.1.0 — 2026-09-29

- UI audit, prototype, approval, implementation, and verification workflows.
- Baoyu-Design integration with versioned prototype approval.
- DOM content auditing and multimodal source tracking.
- Repository cleanup with verified recovery snapshots.
- English and Chinese usage guides.
- Validated ZIP releases through GitHub Actions.
