开发流程

Windows 保存源码与 Git；Debian WSL2 用于可重建的 Linux 构建和测试。

工作区

管理端和公开页属于同一 pnpm workspace。Hub 与 Agent 分别位于 server/ 和 agent/；生产文档位于 docs/。

本地验证

Linux 构建通过 linux-task.ps1 的 build 模式运行。按改动范围执行前端、Rust、脚本和浏览器测试；完整 Linux 门禁入口为 make check-linux。

提交与交付

使用有明确目的的 Conventional Commits。发布和远端操作遵循单独的发布流程，测试结果必须对应实际提交和工件。
