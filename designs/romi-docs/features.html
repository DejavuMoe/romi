功能范围

romi 是单 Hub、多 Agent 的 Linux 主机监测服务。

资源与历史

Agent 上报 CPU、物理内存、ZRAM、Swap、磁盘、网络、进程数、连接数和运行时长。Hub 保存分钟与小时历史；缺少样本的区间保持空白。

监测与通知

TCP 监测使用 host:port 目标，可指定执行节点和间隔。管理员可配置 Telegram、Webhook、离线恢复、流量与到期通知。

公开状态页

公开页默认关闭，新节点默认公开。匿名页面可查看允许公开的节点和历史，但不返回管理地址、备注或凭据。
