文档/部署

部署

Hub 与 Agent 支持 x86_64、ARM64 的 GNU 和 musl Linux 工件。Debian 使用 systemd，Alpine 使用 OpenRC。

安装前

从已发布的归档获取工件，先验证来源证明与 SHA-256，再解压和安装。不要从可变的 master 分支直接执行安装脚本。

选择工件

根据主机架构和 libc 选择对应的 Hub 归档。Agent 可以原生运行；Agent Docker 镜像按 x86_64 和 ARM64 分发。Hub Docker 不在当前支持范围。

验证并安装 Hub

发布归档中包含目标平台的 Hub、Agent、安装器和校验信息。验证完成后，将归档解压到空目录，并从解压目录运行安装器：

mkdir romi-hub
tar -xzf romi-hub-vX.Y.Z-x86_64-unknown-linux-gnu.tar.gz -C romi-hub
sudo sh romi-hub/deploy/hub/install.sh --site https://hub.example.com

Hub 监听回环地址，外部 HTTPS 由可信反向代理提供。安装器不会下载源代码或二进制。

首次登录与节点接入

全新数据库的管理员初始密码写入 /var/lib/romi/bootstrap-password，权限为 0600。修改密码后该文件会删除。

管理员创建节点后，由节点从可信 Hub 获取精确版本的 Agent。下载内容会按大小、SHA-256 和 Agent 版本核验。
