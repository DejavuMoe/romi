发布流程

版本来源是仓库根目录的 VERSION，Hub 与 Agent 使用同一版本号。

候选构建

同一提交先通过 CI 和四个平台构建，再手动组装候选发行包。候选包不自动发布。

发行演练

发行演练使用候选包的相同字节，检查 systemd、TLS、注册、重装与重启持久性。失败或其他提交的结果不能替代本次验收。

版本标签

获授权后，标签工作流核对门禁并复用已验收归档。当前工作流创建 Pre-release，尚未配置稳定版发布。
