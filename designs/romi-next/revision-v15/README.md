# v15 晨昏

状态：已批准（`_d_meta.json` 中为 `approved`），是现行规格。状态页、节点详情、后台登录与导航、节点管理已在生产实现；其他后台页面分批迁移，进度见 `docs/ui/implementation.md`。

入口（先在仓库根运行 `node designs/preview.mjs 4311`）：

- `public.html`：公开状态页，含三维地球与流量动画、卡片/列表和节点详情；
- `index.html`：管理后台，含登录、节点、监测、通知、数据、安全和设置；
- `system.html`：设计规范，亮色和暗色两列并排渲染同一组变量和组件。

原型登录用 `admin` / `romi-prototype`，安全页的「当前密码」也是 `romi-prototype`。连续 4 次登录失败后原型拒绝登录，用于演示；Hub 按来源地址允许 5 次失败，之后锁定 15 分钟。所有节点、地址、令牌和反馈都是合成数据：地址只用 `192.0.2.0/24` 与 `2001:db8::/32`，域名只用 `.invalid`。

## 设计变量

所有样式只取 `styles.css` 中的变量，`tools/css-scale.cjs` 逐条检查：

- 字号 11、12、13、14、16、18、24、32、48、64；行高 1、1.25、1.5、1.7；字重 400、500、600、700；
- 间距 16px 以下取 2 的倍数，以上取 4 的倍数；图标 12、14、16、20、24；
- 圆角按层级取值：浮层（对话框、检查器、登录卡、保存条）20，页面卡片 16，卡片内的面板和控件 10，小按钮、页签和提示 6，标签与计量条全圆；嵌套时内层圆角等于外层减去间距；
- 时长 120ms 到 2400ms 共十档，缓动三种；颜色在主题块之外只用变量；
- 下载固定为蓝色（`--flow-down`）、上传固定为橙色（`--flow-up`），地球、图表、卡片和列表共用；图标与文字同行时垂直居中，数字行高为 1；
- 两列网格中的卡片两两成行且等高，数量为奇数时第一张占满一行；页签切换只改变颜色和下划线。

## 相对 v14 的新增行为

其中公开页的汇总带与地球、页脚昼夜图、搜索面板与中英文已在生产实现，其余随节点详情与管理面板迁移实现：

- 公开页顶部显示在线数、按状态筛选、全体上下行速率与累计流量，旁边是可拖动、会自转的三维点阵地球：陆地按当前太阳位置分昼夜，节点按国家/地区聚合；每个地区的下载从远端流向节点、上传从节点流出，速率越高，弧线越多、粒子越快越亮；右侧列出各地区，悬停或聚焦时地球转向该地区，点击打开节点或多节点摘要；
- 节点详情的定位球使用同一个地球；登录页和未公开页背后是缓慢转动的地平线；
- 公开页页脚是一张按当前太阳位置着色的昼夜点阵世界图，标出各节点位置，每分钟重绘；旁边是版本、连接状态、节点与国家/地区数和页面时间所用的时区；
- 卡片和详情按节点所在国家/地区的代表点和太阳高度，标出当地白天、夜间、黎明或黄昏；
- 卡片显示 CPU 实时曲线、离线时长条，以及本月流量按当前速度推算到周期末的用量；手机上三项用量并排、速率一行，明细留在详情页；
- 界面提供中文和英文，顶栏和登录页可切换，选择保存在本机；
- `/` 或 `Ctrl/⌘+K` 打开搜索面板，按名称、地区和系统查找节点；后台的搜索面板还能跳转页面、执行添加节点等操作；
- 节点详情的历史图十字线在同组图表间同步，可拖选缩放、双击还原、方向键逐点查看，并可切换为表格和平滑显示；
- 后台首页列出需要处理的节点（离线、从未连接、即将到期、流量接近阈值），按严重程度再按列表顺序排列，每行卡片数量均衡；节点列表上方显示最后一次推送的时间，搜索时显示匹配数；
- 编辑节点改为右侧检查器，分概览、设置、账单与流量、安装四个页签，概览与节点详情使用相同的指标块；检查器占满窗口高度，只有内容区滚动，保存行在滚动时停在底部，切换页签不改变尺寸；
- 添加节点分三步：命名、复制安装命令并等待首次连接、显示已接入；批量注册窗口显示剩余时间，并列出窗口期内注册的节点；
- 监测任务的节点选择提供全选、仅在线、清空；
- 品牌标记是肩部为轨道的小写 r 和它前方的探针点：站点正常时探针为品牌紫，需要关注时变为黄色或红色，每次推送泛起一圈；浏览器标签图标为紫底白色标记，探针同样随状态变色；卡片进入详情、切换主题时有过渡动画，数字变化有补间，开启「减少动态效果」后动画停止，地球静止并只画静态弧线。

## 修订的既有约束

v14 的设计输入（`design-sources.json` 中的 `user-brief-v14`）有几条规则，本版提议修改：

| v14 | v15 |
| --- | --- |
| 方正、无阴影，层次只靠 1px 线条 | 圆角 4–20px，弹层使用分层阴影 |
| 整个界面使用等宽字体 | 界面使用系统无衬线字体；数字、地址、标识和命令仍为等宽表格数字 |
| 不加入命令面板 | 加入搜索面板 |
| 只保留 120ms 的颜色与边框过渡 | 加入视图过渡、主题切换的圆形展开、数字补间、地球转动与流量动画，均受减少动态效果控制 |
| 弹窗宽 560px、48px 标题栏 | 节点编辑用侧边检查器；对话框分为居中、贴底和抽屉三种 |
| 空状态用 `[ — ]`、`[ ! ]` 标记 | 空状态和错误使用图标 |
| 只有中文界面 | 中文和英文 |

保持不变：匿名快照不含地址、主机名、备注和凭据；公开历史最多 7 天，延迟最多 24 小时，管理员可查一年；控件在触屏和 767px 以下不低于 44px；焦点可见；历史页签遵循 ARIA tabs。

## 实现约定

- 地球用 Canvas 2D 绘制，不引入三维库；流量弧线的远端是按地区生成的示意点，不代表真实对端，只用现有的节点速率；
- 当地天色和昼夜只在浏览器中计算，不需要新接口；
- 管理面板迁移时，接口返回的错误文案也要能对应到英文词条；
- 「等待首次连接」可以用现有 WS 节点列表判断；列出注册窗口期内的节点需要确认能否从节点创建时间得出，否则需要接口支持；
- 流量推算只用本月已用量和已过时间，不新增存储。
