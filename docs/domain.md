# 领域规则与状态转换

## 节点与会话

节点和探测任务 ID 只前进，删除后不再发放，见[存储](storage.md#标识与关系完整性)。新建节点默认公开；站点公开页默认关闭。
连接状态由 Hub 会话与最后报告时间决定：有活动 Agent 会话为在线；从未报告为未连接；断开后
`online_grace_minutes`（默认 5，可设 1–60）分钟内为重连中，超过为离线。重连中不计入实时在线数量。
永久 Agent 令牌只在创建/轮换时提供明文，数据库保存摘要。轮换/删除要退休旧连接，
旧连接不能在操作完成后继续写入。注册窗口使用短期 key 换取永久令牌，窗口 1 小时、最多 100 个节点，
节点数在插入的同一事务内计数；重新开启窗口会换新 key，关闭窗口后拒绝交换。

登录、凭据修改与会话失效规则见[安全边界](security-baseline.md)。公开页关闭时，匿名访问应进入登录路径；仅隐藏前端按钮不构成授权。

## 流量与采样

Agent 上报内核绝对计数、计数 epoch 与所选接口合计速率。Hub 计算增量并保存累计流量，
断线后可从下一份绝对计数补回；epoch 改变或计数回退重建基线，这一份报告的增量记为 0，不把新旧计数直接相减。
新出现的接口不产生一个采样周期的虚假流量尖峰。`sum/up/down/max` 决定账期用量展示及流量提醒，累计上下行仍分别保存；
服务端不校验模式，未知值按 `sum` 计算。

账期按重置日（1–31，短月落到月末）在 Hub 本地时区划分。本期计数在跨入新账期后的下一次上报时清零，清零前读出为 0；
当日计数按本地日期。手工校正按当前账期记录。

上报间隔范围见[需求](requirements.md) R-01，页面推送节奏见[架构](architecture.md)。分钟历史保存区间摘要，不等于取每分钟某个瞬时值。
过期分钟汇总为小时；汇总与删除在同一事务，重复维护不能重复计数。
CPU/内存/磁盘等按样本数加权；探测按整数延迟的分布计数恢复中位数和丢包，不能平均中位数。
累计流量独立保存，不随历史清理而减少。小时数据参与时，查询桶宽需与整小时对齐。

## 账单

计费周期为 monthly、quarterly、semiannual、yearly、biennial、triennial 或 once。在线且已过期的节点每小时按整周期把到期日向后滚动，
`once` 不滚动。到期日格式为 `YYYY-MM-DD`，价格不小于 0。币种是自由文本，默认 USD；面板提供 USD/CNY/EUR/GBP/JPY 及其符号，不做汇率换算。

## TCP 探测与告警

探测使用 host:port、节点指派及间隔；任务编辑推送到在线 Agent，未变化任务保留计时器。
结果与探测任务绑定。离线不等于延迟 0，失败样本不能当作正常低延迟。

| 告警 | 规则 |
| --- | --- |
| 离线 | 扫描首次发现缺席后满 `notify_grace`（默认 3，1–30 分钟）提醒；1 小时内从长时间离线恢复后再次断开时，满 30 分钟才提醒 |
| 恢复 | 已提醒离线的节点重新上报后提醒 |
| 流量 | 按用量模式，达到阈值（默认 80%，0–100）与 100% 各提醒一次，每个账期每档一次 |
| 到期 | 提前天数默认 7（0 关闭，最多 365）；每天 09:00（Hub 本地时间）起、且已配置渠道时发送一次摘要 |
| 后台登录 | 默认开启 |

已通知状态不能被重复扫描绕过。每个渠道最多尝试 3 次、间隔 10 秒，不可重试的错误立即放弃，不跟随重定向；
事件队列 64，满时丢弃。通知渠道失败需要可观察，不能把本地排队成功解释为外部已送达。

## 数据与安装

schema、DuckDB 引擎、备份格式分别管理，当前取值、备份内容与恢复顺序见[存储](storage.md)。
同版本重装保留数据库和凭据；不能将安装目录作为运行时写目录。

## 浏览器状态

加载、空列表、请求失败、连接中断、权限失效、未配置分发分别表达。
节点编辑只提交改动过的字段；设置页按各区提交字段。空凭据通常表示保留原值，清除凭据必须是明确动作。
HTTP 204 没有 JSON；错误保留状态码以处理 401。上传取消必须取消请求，不能只是关闭弹窗。
从详情返回列表保留合理上下文；深链、刷新与浏览器后退均可用。

## 内存与资源曲线

RAM 已用量为 `MemTotal − MemAvailable`（与 free(1) 一致），缺少 MemAvailable 时用 `MemFree + Buffers + Cached` 估算；
ZRAM 使用 sysfs `mm_stat.mem_used_total`，包含分配器开销；
普通 Swap 排除按设备号识别出的 ZRAM，另给出 Swapfile 与分区的使用量。三条曲线不能堆叠相加。
未启用是零容量/零设备、已启用但未使用是真实零、读取失败或旧 Agent 缺字段是 null；后两者不能混淆。
依据：[Linux ZRAM](https://www.kernel.org/doc/html/latest/admin-guide/blockdev/zram.html)。

## 节点配置与在线时段

优先级为 0–999999 整数，越大越靠前；相同优先级保留排序/id 顺序，排序在浏览器端完成。面板通过展示优先级调整顺序；
批量顺序接口同时写入全节点顺序，并把优先级改写为节点数减序号，覆盖手工设置的值。
可用带宽是手动配置的 Mbps，0 表示未设置，范围 0–1000000；展示时 1000 Mbps = 1 Gbps。流量额度 GB/TB 输入按 1024 换算，保存单位选择；
采集字节量使用 IEC 标签 GiB/TiB，流量提醒消息中的 GB 同样按 1024 进制。
连续在线采用 Hub 接收时间，逐次持久化最后报告时间和时段起点；中断严格超过 `online_grace_minutes` 才在下一次有效报告重建起点。
系统 uptime 独立随启动重置；展示时长不为负。
自动维护周期只接受关闭/7/30/90/180 天，默认关闭；配置后开始计时，每小时检查到期，成功后更新执行时间。历史保留清理独立运行，不清零累计流量。

公开页默认视图通过 `public_default_view` 设置持久化，只接受 `cards` 或 `list`，默认 `cards`。`/api/me` 向访客提供该非敏感展示设置；访客当前页面的切换不写回设置。
IP、主机名与备注只在管理态返回。数字 id 公开，用于 `/node/{id}`；后台以 `node-{id}` 展示，二者都不是凭据。
