# 领域规则与状态转换

## 节点与会话

节点和探测任务 ID 单调递增，删除后不再发放：分配器只前进，启动与恢复都不会把它调回现存最大 ID，详见[存储](storage.md)。新建节点默认公开；站点公开页仍默认关闭，升级不改变既有私有节点。未连接、重连中、在线、离线分别表达。
永久 Agent 令牌只在创建/轮换时提供明文，数据库保存摘要。轮换/删除要退休旧连接，
旧连接不能在操作完成后继续写入。注册窗口使用短期 key 换取永久令牌；关闭窗口后拒绝交换。

本地登录必须同时校验账号和密码；未设置账号时为 admin，原密码不变。修改账号或密码必须同时提交当前密码，会话本身不构成凭据证明。注销、撤销、修改账号/密码、恢复数据库分别触发相应会话失效。
密码校验昂贵，使用并发门限和失败节流。
公开页关闭时，匿名访问应进入登录路径；仅隐藏前端按钮不构成授权。

## 流量与采样

Agent 上报内核绝对计数、计数 epoch 与所选接口合计速率。Hub 计算增量并保存累计流量，
断线后可从下一份绝对计数补回；epoch 改变或计数回退重建基线，不把新旧计数直接相减。
新出现的接口不产生一个采样周期的虚假流量尖峰。`sum/up/down/max` 决定账期用量展示及流量提醒，累计上下行仍分别保存。

实时指标默认 3 秒，上报间隔只接受 3–60 秒整数；页面推送默认 2 秒。分钟历史保存区间摘要，不等于取每分钟某个瞬时值。
过期分钟汇总为小时；汇总与删除在同一事务，重复维护不能重复计数。
CPU/内存/磁盘等按样本数加权；探测按整数延迟的分布计数恢复中位数和丢包，不能平均中位数。
累计流量独立保存，不随历史清理而减少。小时数据参与时，查询桶宽需与整小时对齐。

## TCP 探测与告警

探测使用 host:port、节点指派及间隔；任务编辑推送到在线 Agent，未变化任务保留计时器。
结果与探测任务绑定。离线不等于延迟 0，失败样本不能当作正常低延迟。
告警区分离线宽限、恢复、流量阈值和每日到期摘要；抖动抑制与已通知状态不能被重复扫描绕过。
通知渠道失败需要可观察，不能把本地排队成功解释为外部已送达。

## 数据与安装

schema、DuckDB 引擎、备份格式分别管理。当前为 schema 3 / 备份格式 3。
备份是受限 tar.gz + Parquet + manifest，所有表来自同一只读快照，session 不进入备份。
恢复先校验归档和关系、建立 staging 库，再在替换栅栏内切换；失败要保留/恢复原库。
同版本重装保留数据库和凭据；不能将安装目录作为运行时写目录。

## 浏览器状态

加载、空列表、请求失败、连接中断、权限失效、未配置分发分别表达。
节点编辑只提交改动过的字段；设置页按各区提交字段。空凭据通常表示保留原值，清除凭据必须是明确动作。
HTTP 204 没有 JSON；错误保留状态码以处理 401。上传取消必须取消请求，不能只是关闭弹窗。
从详情返回列表保留合理上下文；深链、刷新与浏览器后退均可用。

## 内存与资源曲线

RAM 使用物理内存已用量；ZRAM 使用 sysfs `mm_stat.mem_used_total`，包含分配器开销；
普通 Swap 排除按设备号识别出的 ZRAM，另给出 Swapfile 与分区的使用量。三条曲线不能堆叠相加。
未启用是零容量/零设备、已启用但未使用是真实零、读取失败或旧 Agent 缺字段是 null；后两者不能混淆。
依据：[Linux ZRAM](https://www.kernel.org/doc/html/latest/admin-guide/blockdev/zram.html)。

## 节点配置与在线时段

优先级为 0–999999 整数，越大越靠前；相同优先级保留排序/id 顺序。面板通过展示优先级调整顺序；批量顺序接口仍同时写入全节点顺序和对应优先级。
可用带宽是手动配置的 Mbps，0 表示未设置，范围 0–1000000；展示时 1000 Mbps = 1 Gbps。流量额度 GB/TB 输入按 1024 换算，保存单位选择；采集字节量使用 IEC 标签 GiB/TiB。
连续在线采用 Hub 接收时间，逐次持久化最后报告时间和时段起点；默认中断严格超过 5 分钟才在下一次有效报告重建起点，可配置 1–60 分钟。重连中不计入实时在线数量。系统 uptime 独立随启动重置；展示时长不为负。
自动维护周期只接受关闭/7/30/90/180 天，默认关闭；配置后开始计时，每小时检查到期，成功后更新执行时间。历史保留清理仍独立运行，不清零累计流量。

公开页默认视图通过 `public_default_view` 设置持久化，只接受 `cards` 或 `list`，默认 `cards`。`/api/me` 向访客提供该非敏感展示设置；访客当前页面的切换不写回设置。后台节点页仅使用管理列表，IP 和节点标识只在管理态显示；`node-{id}` 是既有节点 ID 的展示形式，不是认证凭据。
