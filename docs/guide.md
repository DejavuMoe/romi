# 日常使用

完成[快速开始](quick-start.md)后，通过 `/admin/` 管理节点。公开状态页位于 `/`，默认关闭。

## 查看节点与流量

后台「节点」页列出已创建的节点，可以按名称、IP 或节点标识搜索，也可以筛选在线与离线节点。新建节点在 Agent 首次上报后显示系统信息和资源用量。

- **编辑**：修改名称、公开范围、展示优先级、可用带宽与流量额度。优先级越大，位置越靠前。
- **账单与流量**：记录价格、币种、付款周期和到期日期。账单是记录用途，不连接支付平台。
- **安装**：获取该节点的安装命令。永久令牌只在创建或换发时显示；遗失后需要换发并重新安装 Agent。
- **批量注册**：为多台主机生成一条临时安装命令。窗口关闭后，已注册的节点继续使用各自的永久令牌。

累计流量、本期流量和瞬时速率含义不同。本期用量按节点设置的上传、下载、双向合计或较大值计算；重置日与到期日也互相独立。具体计算见[节点、流量与告警](domain.md)。

### 在线状态

| 状态 | 含义 |
| --- | --- |
| 在线 | Agent 已连接 Hub |
| 重连中 | 连接断开，但仍在在线宽限时间内 |
| 离线 | 断开时间超过在线宽限 |
| 未连接 | 节点尚未上报过数据 |

在线宽限与离线通知等待时间是两项独立设置。页面显示离线，不表示通知已经送达。

### 查看历史

点击节点名称进入详情，切换资源、监测或流量页签并选择时间范围。历史中的空白表示没有样本，不能作为零用量或零延迟解读。历史保留时间与查询范围见[存储](storage.md#两级历史)。

## 配置监测与通知

1. 在「监测」中创建 TCP 任务，填写名称、`host:port` 和间隔，选择执行探测的节点。IPv6 目标使用 `[地址]:端口`。
2. 在节点详情的监测页查看延迟与丢包。探测从所选 Agent 发起，不是从浏览器或 Hub 发起；目标需要从这些主机可达。
3. 在「通知」中配置 Telegram 或 Webhook，保存后发送测试消息。有未保存修改时，先保存再测试。
4. 选择需要离线提醒的节点，并配置等待时间、流量阈值和到期提醒。

TCP 探测不检查 HTTP 状态码或页面内容。当前通知包括节点离线与恢复、流量、到期和后台登录，不提供 TCP 延迟阈值告警。

已保存的渠道凭据不回显，留空表示保留；需要移除时使用清除操作。模板留空保存则恢复默认模板。各类通知的触发条件见[告警规则](domain.md#tcp-探测与告警)。

## 开放状态页

1. 在「节点」中检查各节点的「公开状态页」选项。新节点默认公开。
2. 在「设置」中开启公开页，选择默认卡片或列表视图。
3. 使用未登录的浏览器检查展示范围。已登录管理员能看到私有节点，不适合用于验证匿名视图。

访客可以查看公开节点的状态与历史，也可以临时切换卡片/列表、中英文和明暗主题。访客的视图切换不会改写管理员保存的默认值。

匿名响应不包含 IP、主机名、备注、节点令牌和探测目标。节点名称、地区、账单信息和资源数据仍可能公开，发布前检查这些内容是否适合展示。

地球按国家/地区标记节点，流线表现上下行速率。标记与流线是示意，不表示服务器的精确位置或真实网络对端。

## 备份与维护

在「数据」页下载备份，升级前保留一份。备份包含管理配置和凭据摘要，应放在受限目录中；不要复制正在运行的 DuckDB 文件作为备份。

恢复会替换当前数据并使旧登录会话失效，当前操作人会获得新会话，Agent 重新连接。执行前核对文件与版本，具体限制见[备份格式与限制](storage.md#备份格式与限制)。

历史按保留期自动清理。手动维护与周期维护用于数据库空间整理，不会清零累计流量；周期维护默认关闭。

## 账号与会话

在「安全」页修改账号或密码，需要填写当前密码。修改后本设备保持登录，其他设备需要重新登录。可以在会话列表中单独撤销其他设备。

连接或安装异常时，先查看[部署与升级](deployment.md#故障排查)。报告问题请附版本、部署方式、复现步骤和去除凭据后的错误信息；安全漏洞按[安全策略](https://github.com/DejavuMoe/romi/blob/master/SECURITY.md)私密报告。
