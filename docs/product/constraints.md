# 产品与界面约束

- 单 Hub、多 Linux Agent，DuckDB 是唯一生产数据库；范围由[需求](../requirements.md)定义。
- 后台节点页只使用管理列表；公开页支持卡片/列表，默认值规则见[领域规则](../domain.md)。
- 匿名页面不展示 IP、备注或凭据；隐藏按钮不能代替服务端权限检查。
- 320 CSS px 起适配。移动端保持主要操作可达；IPv6 与错误允许换行，状态页卡片的节点名单行省略，列表与详情显示完整名称。
- 单位与数值同行，变化不推动相邻内容；令牌、字体与文案语言见[界面实现](../ui/implementation.md)。
- 触摸目标至少 44px，键盘焦点可见；弹窗可取消并返回触发点。
- 实色表面、细分隔线，不使用背景模糊。
- 在线与正常资源为绿色，高用量使用琥珀/红色；文字或形状同时表达状态。
- 输入框聚焦不增加底线或粗黑外框。错误就地显示，不推动其他控件。
- 复制图标贴近值，桌面悬浮/聚焦显示，触屏保留淡色提示。导航开关不改变底层布局。
- 产品文案只表达对象、操作、状态和必要帮助；设计解释、实现过程和任务指令不进入产品内容。

当前界面规格在 `designs/romi-next/revision-v15/`，状态与源文件映射见 `ui-contract.json`，能力和边界见[UI 能力](../ui/capabilities.md)。
