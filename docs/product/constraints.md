# 产品与界面约束

- 单 Hub、多 Linux Agent，DuckDB 是唯一生产数据库；范围由 [需求](../requirements.md) 定义。
- 后台节点页只使用管理列表；公开页支持卡片/列表，默认值由管理员保存。
- 匿名页面不展示 IP、备注或凭据；隐藏按钮不能代替服务端权限检查。
- 320 CSS px 起适配。移动端保持主要操作可达；长名称、IPv6 和错误允许换行。
- 中文为主要文案，数值使用等宽数字；单位与数值同字号、同行，变化不推动相邻内容。
- 触摸目标至少 44px，键盘焦点可见；弹窗可取消并返回触发点。
- 两种主题共用 `styles/theme.css`：实色表面、细分隔线和蓝色操作色，不使用透明卡片或背景模糊。
- 在线与正常资源为绿色，高用量使用琥珀/红色；文字或形状同时表达状态。
- 输入框聚焦不增加底线或粗黑外框。错误就地显示，不推动其他控件。
- 复制图标贴近值，桌面悬浮/聚焦显示，触屏保留淡色提示。导航开关不改变底层布局。
- 产品文案只表达对象、操作、状态和必要帮助；设计解释、实现过程和任务指令不进入产品内容。
- 原型使用合成数据，与生产资源、认证和安装行为分开。

当前界面规格在 `designs/romi-next/ui-contract.json`，能力和边界见 [UI 能力](../ui/capabilities.md)。
