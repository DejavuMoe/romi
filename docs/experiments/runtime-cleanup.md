## 范围与依据

| 变体 | 改动 | 保留理由与边界 |

| 死代码 | 删除未调用的 Card 插槽、Separator、Table/Select 插槽、DialogClose、footer 可选分支、速率历史缓冲及旧轴函数 | 静态引用检查、类型构建和真实页面比较；不移除仍使用的 Radix、d3-array 或选择器动画 |

| 工具函数 | 删除废弃日历网格和未导入的公开页 Card；复用 unitOf 与原生 Intl 格式化函数 | 日期校验保留；活跃格式化输出差分比较 110,033 次 |

旧设计和移出文件留在仓库外恢复目录，当前 v12 的 35 个文件逐字节未改。

- 移出 40 个文件，共 24,815,428 字节，主要是历史设计素材；这不是线上下载量减少。
- 前端目录与样式文本行数（含同目录测试和注释）：4,882 → 4,514，减少 368 行。
- 未增加或删除运行时依赖。

gzip 使用 Python 标准库相同参数计算，不与其他工具的压缩设置混比。

## 验证与复现

Windows 执行格式化差分与 Git 读取；Linux ext4 执行构建和浏览器测试。每次同步后先构建前端，再构建嵌入它的 Hub。

```sh
make frontend check-frontends
cargo build --locked --release --manifest-path server/Cargo.toml
ROMI_E2E_BIN_DIR=server/target/release ROMI_VISUAL_REFERENCE=/tmp/romi-visual-reference pnpm test:e2e
```

在干净基线加相同夹具时，额外设置 `ROMI_VISUAL_RECORD=1` 记录截图。候选比较时不设置该变量。
比较节点、监测、通知与公开页，覆盖桌面/移动和明暗主题，共 16 张 PNG，SHA-256 全部相等。
这些固定样本不代表每一种状态都已做像素比较；其余交互由 48 项 E2E 覆盖。

`node scripts/frontend_ablation.mjs <baseline-format.mts> [result.json]` 对显式基线模块执行差分检查。
基线模块和它的共享依赖应来自同一源树，不用当前依赖冒充旧实现。此次模块及截图原件保存在仓库外恢复材料中。

通过的检查：两端构建/类型/lint/单元检查、Hub release 构建与 fmt、48/48 E2E、110,033 次格式化输出比较、15 项发布工具检查、快照安全检查及发布矩阵测试。
内置浏览器另检查了实际卡片与六类资源详情，没有观察到控制台错误。
未重跑未修改的 Hub/Agent 全量逻辑测试、真实手机或真实服务器安装演练；没有改变生产 API、数据库和采集逻辑。
