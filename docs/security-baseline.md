# 安全边界

发现漏洞请按[安全策略](https://github.com/DejavuMoe/romi/blob/master/SECURITY.md)通过 GitHub 私密报告，不要公开提交 Issue。本页描述现有的安全机制与明确不保证的内容。

## 身份与权限

- 管理 API 使用会话认证；账号密码是唯一的登录方式，登录同时校验账号与密码。
- 密码以 argon2 摘要保存；同一时刻只做 1 个密码校验，超出即拒绝而不排队；每个来源地址失败 5 次后锁定 15 分钟。
- 会话 Cookie 为 `HttpOnly`、`SameSite=Lax`，配置了 https `--site` 或收到 `X-Forwarded-Proto: https` 时加 `Secure`，有效期 14 天；`session` 表只存令牌摘要。
- 修改账号或密码必须提交当前密码，与登录共用同一并发门限，会话本身不是凭据证明；新密码至少 12 字节。修改后注销全部会话并给当前操作人重新签发。注销、撤销与恢复数据库同样使相应会话失效。
- 节点永久令牌只在创建/轮换时展示，数据库保存摘要；轮换或删除会退休旧连接。
- 创建节点、轮换令牌、开启注册窗口和用注册 key 换令牌都要求 HTTPS 域名入口（HTTPS 协议、域名 `Host`、同源 `Origin`），因为它们返回或发放长期凭据。
- 注册窗口使用短期 key 换取独立节点令牌，错误 key 单独节流。
- 公开页默认关闭，权限在 Hub 判断，不依赖按钮隐藏。匿名视图不含主机名、IP、备注与通知设置；实时指标按白名单过滤，不透出 `boot_id` 与内核网络累计计数；
  单节点历史要求公开页开启且该节点公开；探测只返回名称，不含目标。数字 id 公开，用于 `/node/{id}`，与 `node-{id}` 一样不能认证。
- 密码校验、连接、历史查询与上报都有准入/尺寸限制，匿名与管理各有独立配额，数值见[架构](architecture.md)。
- 两套前端页面返回 `Content-Security-Policy`、`X-Frame-Options: DENY`、`X-Content-Type-Options` 和 `Referrer-Policy`。策略按实际返回的 HTML 计算内联脚本哈希，不使用 `script-src 'unsafe-inline'`；`frame-ancestors 'none'` 防止管理界面被嵌套。

## 传输与分发

Hub 默认回环监听，可信反向代理终止 HTTPS。

两类转发头的信任级别不同，是有意区分：`X-Forwarded-For` 只在对端为回环时采信，因为它用于限流计数和地址展示，可被调用方自由伪造；
`X-Forwarded-Proto` 与 `Host` 用于判断入口是否为 HTTPS 域名，前提是代理不可绕过——Hub 端口一旦对外可达，调用方即可自设这两个头。
因此监听非回环地址时 Hub 会在启动日志中警告，部署要求见[部署](deployment.md)的反向代理一节。
Agent 始终验证 TLS，只信任二进制内置的公共 Web PKI 根证书，不读取系统信任库：私有 CA 或自签名证书无法连接。
`--insecure` 只允许到远程 Hub 的明文 `ws://`（令牌明文传输），属于受控网络选项；不存在关闭证书校验的选项。
安装器只下载本 Hub 的已验证精确版本工件并校验摘要，任何安装路径都不使用 `curl -k`；永久令牌从终端（不回显）或标准输入（`--token-stdin`）读取，不进入 shell 历史或 argv；
批量注册的短期 key 通过 `--register-key` 传入。
国家数据库从管理员配置的 HTTPS 地址下载，校验类型、格式与大小（≤ 32 MiB）后存于本地；不在运行时下载并执行第三方主题或可变 latest 二进制。

## 数据与运维

DuckDB 文件、WAL、spill、锁与 bootstrap 凭据限制为服务账号可读写。数据库和备份仍包含敏感管理配置。
恢复先验证归档、schema、关系与摘要，在文件替换栅栏内切换；失败保留或恢复旧库，不恢复旧登录会话。
日志、截图、CI 报告不得携带永久凭据或生产数据库。测试使用独立回环实例和合成数据。
发布只复用已验收字节，按[发布流程](release.md)核对来源和完整性。

本文件描述实现边界，不代表全面安全审计、完整 SBOM、密码学擦除或所有部署环境的保证。
